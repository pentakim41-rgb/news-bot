========================================
  네이트뉴스 AI 블로그 - 사용 안내
========================================

■ 실행 방법
  1. 이 폴더 전체를 원하는 위치에 복사합니다.
  2. 「네이트뉴스AI블로그.exe」를 실행합니다.
  3. 관리자에게 받은 아이디/비밀번호로 로그인합니다.

■ 첫 실행 시 설정 (프로그램 GUI)
  - 텍스트 AI API 키: Google Gemini API 키 입력
  - 이미지 AI API 키: Hugging Face 토큰 (hf_...) 입력
    발급: https://huggingface.co/settings/tokens
  - 🐙 깃허브 탭: 본인 GitHub 아이디·토큰·저장소 입력 (업로드용)
    ※ 로그인 DB는 관리자 설정이 config.json에 포함되어 있습니다.
  - 설정 후 「저장」 클릭

■ 뉴스 수집 소스
  - 네이트온: 경제/사회/스포츠/연예 카테고리 선택
  - 구글: 구글 트렌드 실시간 인기 검색어 (ms-playwright 폴더 필요)
    ※ 구글 트렌드 사용 시 release 폴더의 ms-playwright 폴더를
      exe와 같은 위치에 반드시 함께 두세요.

■ 폴더 구성 (exe와 같은 위치)
  네이트뉴스AI블로그.exe  ← 실행 파일
  config.json              ← 설정 (자동 생성/저장)
  data\                    ← 수집·생성 결과 저장
  ms-playwright\           ← 구글 트렌드용 크로미움 (배포 패키지에 포함)

■ 계정 문의
  - 로그인 아이디/비밀번호는 관리자에게 요청하세요.
  - 비밀번호 분실 시 관리자가 재설정해 드립니다.

■ 주의
  - Windows 전용 / 인터넷 연결 필요
  - exe만 따로 옮기지 말고 폴더 전체를 배포하세요.
  - 백신이 exe를 차단할 수 있습니다. 신뢰할 수 있는 출처임을 확인 후 예외 추가하세요.
